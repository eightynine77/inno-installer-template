# inno installer template
this is a reusable template for inno setup. you can replace the components in the code with your components

# how to use  
### step 1 - download the `.iss` file
<img src="https://raw.githubusercontent.com/eightynine77/inno-installer-template/refs/heads/main/imgaes/step%201.png"/>  
<img src="https://raw.githubusercontent.com/eightynine77/inno-installer-template/refs/heads/main/imgaes/step%202.png" width="900" height="354"/>  

### step 2 - load the `.iss` file
go to **file>open** and select the `.iss` file to open it.

### step 3, final step - customize the file
since the file is for an [app i made](https://github.com/eightynine77/pally-file-paste/), you need to modify the file to suit your needs. there are code comments (this one: `;`) that will guide you on modifying the file.
